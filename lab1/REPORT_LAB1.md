# Лабораторна робота №1: Інтерполяція кубічними сплайнами

**Мета:** дослідити метод інтерполяції кубічними сплайнами та застосувати його до реальних GPS-геоданих висотного профілю маршруту Заросляк – Говерла.

---

## 1. Короткі теоретичні відомості

Кубічний сплайн на кожному інтервалі $[x_{i-1}, x_i]$ ($i = 1, \dots, n$):
$$S_i(x) = a_i + b_i(x - x_{i-1}) + c_i(x - x_{i-1})^2 + d_i(x - x_{i-1})^3$$

З умов інтерполяції $S_i(x_{i-1}) = y_{i-1}$, $S_i(x_i) = y_i$ та гладкості $S'_i(x_i) = S'_{i+1}(x_i)$, $S''_i(x_i) = S''_{i+1}(x_i)$ отримуємо тридіагональну СЛАР для коефіцієнтів $c_i$ (при $c_1 = c_{n+1} = 0$):
$$\alpha_i c_{i-1} + \beta_i c_i + \gamma_i c_{i+1} = \delta_i$$
де $\alpha_i = h_{i-1}$, $\beta_i = 2(h_{i-1} + h_i)$, $\gamma_i = h_i$, $\delta_i = 3\left(\frac{y_i - y_{i-1}}{h_i} - \frac{y_{i-1} - y_{i-2}}{h_{i-1}}\right)$, $h_i = x_i - x_{i-1}$.

Система розв'язується **методом прогонки** ($O(N)$ операцій):
- **Прямий хід:** $P_k = \frac{-\gamma_k}{\beta_k + \alpha_k P_{k-1}}$, $Q_k = \frac{\delta_k - \alpha_k Q_{k-1}}{\beta_k + \alpha_k P_{k-1}}$
- **Зворотний хід:** $c_m = Q_m$, $c_k = P_k c_{k+1} + Q_k$

Решта коефіцієнтів:
$$a_i = y_{i-1}, \quad d_i = \frac{c_{i+1} - c_i}{3 h_i}, \quad b_i = \frac{y_i - y_{i-1}}{h_i} - \frac{2 c_i + c_{i+1}}{3} h_i$$

## 2. Результати роботи

1. **Вхідні дані:** отримано 21 точку від Open-Elevation API. Розраховано кумулятивну відстань за формулою Гаверсинуса (збережено у `tabulation.txt`).
2. **Характеристики маршруту:**
   - Загальна довжина: **3069.3 м** (3.07 км).
   - Сумарний підйом: **790.0 м**, сумарний спуск: **23.0 м**.
   - Максимальний підйом: **+134.7%**, максимальний спуск: **-35.4%**, середній градієнт: **27.9%**.
   - Механічна робота сходження ($m = 80$ кг): **620.0 кДж** (**148.2 ккал**).

3. **Оцінка точності для різної кількості вузлів:**
   | Кількість вузлів | Максимальна похибка (м) |
   |:---:|:---:|
   | 10 | 72.26 м |
   | 15 | 68.95 м |
   | 20 | **7.69 м** |

4. **Графік інтерполяції:**
   Збережено у файлі `profile_splines.png`. При 20 вузлах сплайн ідеально повторює реальний профіль Говерли, похибка падає до 7.7 м.

## 3. Відповіді на контрольні питання

1. **Що таке табуляція?**  
   Обчислення та представлення значень функції або координат у вигляді структурованої таблиці $\{x_i, y_i\}$ у дискретних вузлах.
2. **Що таке інтерполяція?**  
   Побудова неперервної функції $S(x)$, яка у всіх заданих вузлах точно збігається зі значеннями вибірки: $S(x_i) = y_i$.
3. **Що таке кубічний сплайн?**  
   Кусково-поліноміальна функція третього степеня, двічі неперервно диференційовна ($C^2$) на всьому відрізку інтерполяції.
4. **Яка система рівнянь виникає при побудові сплайна?**  
   Тридіагональна система лінійних рівнянь відносно коефіцієнтів $c_i$ (других похідних у вузлах).
5. **Що таке метод прогонки?**  
   Економічний прямий метод розв'язання СЛАР із тридіагональною матрицею (прямий та зворотний хід) зі складністю $O(N)$.
6. **Який порядок точності кубічного сплайна?**  
   4-й порядок за кроком сітки: $\|f - S\| = O(h^4)$.
7. **Які коефіцієнти визначаються та як вони обчислюються?**  
   $a_i = y_{i-1}$; $c_i$ — з методу прогонки; $d_i = (c_{i+1} - c_i) / (3h_i)$; $b_i = (y_i - y_{i-1})/h_i - (2c_i + c_{i+1})h_i / 3$.

---

## 4. Висновок
Реалізовано алгоритм побудови кубічного сплайна та розв'язання тридіагональної матриці методом прогонки. На прикладі маршруту Заросляк – Говерла показано, що сплайн забезпечує високу гладкість ($C^2$) без паразитних коливань Рунге, а збільшення вузлів з 10 до 20 знижує похибку апроксимації майже в 10 разів (до 7.7 м).
