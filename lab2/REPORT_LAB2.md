# Лабораторна робота №2: Розділені різниці. Інтерполяційні многочлени Ньютона та факторіальних многочленів

**Варіант 1:** Інженерія продуктивності. Прогнозування часу виконання алгоритму.  
**Мета:** опанувати методи обчислення розділених і скінченних різниць, побудувати інтерполяційні многочлени Ньютона та факторіальні многочлени для прогнозування часової складності алгоритму.

## 1. Короткі теоретичні відомості

### 1.1. Інтерполяційний многочлен Ньютона з розділеними різницями

Для довільної сітки вузлів $x_0, x_1, \dots, x_n$:

- **Розділена різниця 0-го порядку:** $f[x_i] = y_i$
- **Розділена різниця $k$-го порядку:**
  $$f[x_i, \dots, x_{i+k}] = \frac{f[x_{i+1}, \dots, x_{i+k}] - f[x_i, \dots, x_{i+k-1}]}{x_{i+k} - x_i}$$
- **Многочлен Ньютона (інтерполяція вперед):**
  $$P_n(x) = f[x_0] + f[x_0, x_1](x - x_0) + \dots + f[x_0, \dots, x_n] \prod_{j=0}^{n-1}(x - x_j)$$

### 1.2. Факторіальні многочлени та скінченні різниці

Для рівновіддалених вузлів ($q = \frac{x - x_0}{h}$):

- **Скінченні різниці:** $\Delta y_0 = y_1 - y_0$, $\Delta^k y_0 = \Delta^{k-1}y_1 - \Delta^{k-1}y_0$
- **Факторіальний степінь:** $q^{[k]} = q(q - 1)\dots(q - k + 1)$
- **Ряд по факторіальних многочленах:**
  $$P_n(q) = \sum_{k=0}^n \frac{\Delta^k y_0}{k!} q^{[k]}$$

## 3. Відповіді на контрольні питання

1. **Що називається інтерполяцією? У чому її відмінність від екстраполяції?**  
   Інтерполяція — це знаходження проміжних значень функції всередині інтервалу між відомими вузлами ($x \in [x_0, x_n]$). Екстраполяція — оцінка значень за межами цього інтервалу ($x < x_0$ або $x > x_n$).
2. **У яких випадках застосовується інтерполяційний многочлен?**  
   Коли аналітичний вигляд функції невідомий (є лише табличні/експериментальні точки), або коли обчислення вихідної функції занадто складне чи дороге.
3. **Що таке вузли інтерполяції?**  
   Задані дискретні точки $x_i$, у яких відомі точні значення досліджуваної величини $y_i = f(x_i)$.
4. **Яка максимальна степінь інтерполяційного многочлена при $n+1$ вузлах?**  
   Степінь не перевищує $n$.
5. **У чому полягає метод Ньютона?**  
   У побудові інтерполяційного полінома через базисні добутки $\prod (x - x_j)$ та коефіцієнти, що є розділеними різницями.
6. **Що таке розділена різниця нульового, першого та вищих порядків?**  
   0-го порядку — значення у вузлі $f[x_0] = y_0$; 1-го — відношення різниці значень до різниці аргументів $\frac{y_1 - y_0}{x_1 - x_0}$; вищих порядків — рекурентна різниця двох різниць попереднього порядку, поділена на повний крок між крайніми вузлами.
7. **Як формується таблиця розділених різниць?**  
   У формі трикутної матриці: кожен елемент наступного стовпця обчислюється через два сусідні елементи попереднього стовпця та відповідні вузли.
8. **Запишіть загальний вигляд інтерполяційного многочлена Ньютона.**  
   $$P_n(x) = f[x_0] + \sum_{k=1}^n f[x_0, \dots, x_k] (x - x_0)(x - x_1)\dots(x - x_{k-1})$$
9. **Які переваги має форма Ньютона порівняно з формою Лагранжа?**  
   Потребує менше арифметичних операцій ($O(n^2)$ замість $O(n^3)$), а при обчисленні використовує ефективну схему Горнера.
10. **Чому форма Ньютона зручна при додаванні нових вузлів?**  
    Усі раніше обчислені коефіцієнти залишаються незмінними; для врахування нового вузла достатньо лише додати один новий доданок.
11. **Які основні етапи обчислення факторіальних многочленів?**
    1. Перехід до нормованої змінної $q = (x - x_0)/h$; 2) побудова таблиці скінченних різниць $\Delta^k y_0$; 3) обчислення факторіальних степенів $q^{[k]}$; 4) підсумовування ряду $\sum \frac{\Delta^k y_0}{k!} q^{[k]}$.
12. **У чому різниця між факторіальними многочленами та многочленами Ньютона?**  
    Многочлен Ньютона з розділеними різницями працює для довільної (нерівномірної) сітки, тоді як факторіальний многочлен застосовується виключно для рівновіддалених вузлів через скінченні різниці.

## 4. Висновок

За допомогою многочлена Ньютона та факторіальних многочленів побудовано модель продуктивності алгоритму $t(n)$. Спрогнозований час виконання для $n = 6000$ становить $\approx 18.85$ мс. Показано, що форма Ньютона збігається за точністю з поліномом Лагранжа, але є значно зручнішою в обчисленнях.
