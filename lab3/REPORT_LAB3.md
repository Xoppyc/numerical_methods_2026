# Лабораторна робота №3: Метод найменших квадратів (МНК)

**Тема:** Знаходження алгебраїчних многочленів найкращого квадратичного наближення методом найменших квадратів.  
**Мета:** вивчити метод найменших квадратів (МНК) для апроксимації емпіричних даних, реалізувати розв'язання системи нормальних рівнянь методом Гауса з вибором головного елемента та оцінити якість моделі для прогнозування.

---

## 1. Короткі теоретичні відомості

### 1.1. Постановка задачі МНК
Шукаємо апроксимуючий многочлен степеня $m < N$:
$$P_m(x) = c_0 + c_1 x + c_2 x^2 + \dots + c_m x^m = \sum_{j=0}^m c_j x^j$$

Коефіцієнти $c_j$ знаходять з умови мінімізації суми квадратів нев'язок:
$$S(c_0, \dots, c_m) = \sum_{k=1}^N (P_m(x_k) - y_k)^2 \to \min$$

### 1.2. Система нормальних рівнянь
Прирівнюючи частинні похідні $\frac{\partial S}{\partial c_i} = 0$ ($i = 0, \dots, m$), отримуємо лінійну систему $(m+1) \times (m+1)$:
$$\sum_{j=0}^m c_j \left(\sum_{k=1}^N x_k^{i+j}\right) = \sum_{k=1}^N y_k x_k^i, \quad i = 0, 1, \dots, m$$

Матриця системи $A c = b$ є симетричною і додатно визначеною. Система розв'язується **методом Гауса з вибором головного елемента по стовпчиках**, що усуває ділення на малі числа та мінімізує похибки округлення.

### 1.3. Дисперсія та вибір оптимального степеня
Якість наближення оцінюється дисперсією залишків:
$$\delta^2 = \frac{1}{N} \sum_{k=1}^N (y_k - P_m(x_k))^2$$
Оптимальний степінь обирається за мінімумом дисперсії без перевищення розумної складності моделі (щоб уникнути перенавчання).

## 3. Відповіді на контрольні питання

1. **У чому полягає суть методу найменших квадратів (МНК)?**  
   У підборі параметрів аналітичної функції, яка мінімізує суму квадратів відхилень між фактичними експериментальними точками та значеннями моделі.
2. **Чим відрізняється апроксимація за МНК від інтерполяції?**  
   При інтерполяції крива зобов'язана проходити точно через усі вузли ($P(x_i) = y_i$), що чутливо до шумів. МНК згладжує випадкові похибки вимірювань і знаходить усереднену закономірність ($m < N$).
3. **Як формується система нормальних рівнянь?**  
   Шляхом диференціювання функції суми квадратів нев'язок за кожним шуканим коефіцієнтом $c_i$ і прирівнювання похідних до нуля: $\partial S / \partial c_i = 0$.
4. **Чому використовується метод Гауса з вибором головного елемента?**  
   Елементи нормальної матриці виду $\sum x_k^{i+j}$ швидко зростають за порядком величини (матриця погано обумовлена). Вибір найбільшого за модулем елемента в стовпці запобігає діленню на малі числа та забезпечує чисельну стійкість.
5. **Як обирається оптимальний степінь полінома?**  
   Критерієм є стабілізація або мінімізація дисперсії (похибки апроксимації). При занадто малому $m$ модель «недоапроксимована», а при занадто великому $m$ виникає перенавчання та паразитні осциляції.
6. **Які особливості та обмеження поліноміальної екстраполяції?**  
   Поліноми на краях інтервалу прямують до $\pm\infty$, тому поліноміальна екстраполяція придатна лише для малого кроку прогнозу; для періодичних процесів доцільніше використовувати тригонометричні ряди (Фур'є).

---

## 4. Висновок
Реалізовано метод найменших квадратів для температурного ряду. Доведено, що для 24-місячних даних із двома періодами коливань оптимальним алгебраїчним поліномом є $m = 4$, який зменшує дисперсію у 2.6 рази (з 75.5 до 29.2). Показано як переваги МНК для згладжування шумів, так і межі застосовності поліноміальної екстраполяції за межі вихідного інтервалу.
